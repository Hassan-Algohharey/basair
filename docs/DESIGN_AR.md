# التصميم المبدئي — بصائر

تحديث النسخة 0.2.0: استُبدلت المقدمات بخمسة كتب PDF كاملة. القارئ يعرض الأصل مع التكبير والانتقال للصفحة واستئناف القراءة، وتعرض المقارنة خمس مسائل بإحالات الجزء والصفحة والطبعة. الصور الجديدة في `screenshots/v02/`؛ الصور الأقدم أدناه توثق تصميم النسخة 0.1.0.

## الاسم

الاسم المقترح: **بصائر**. العبارة التعريفية: «علمٌ تقرؤه، ومصدرٌ تعرفه».
بدائل ممكنة: «روافد»، «مَعين»، «مدارك». لم يجرِ فحص العلامات أو إتاحة أسماء التطبيقات.

## الهوية

- أخضر داكن `#195444` للأزرار والعناصر الرئيسية.
- عاجي `#F7F5EF` للخلفية، وأبيض للبطاقات.
- ذهبي `#B18B47` للتفاصيل والزخرفة.
- نص أخضر شديد القتامة `#173E35`، ورمادي مخضر للنص الثانوي.
- أيقونات خطية بسيطة مرسومة داخل التطبيق وشعار كتاب مفتوح.
- العربية واتجاه اليمين إلى اليسار، مع حقول ذات تسميات عربية.
- بطاقات مستديرة، مسافات مريحة، وشريط تنقل سفلي بخمس وجهات.

## الشاشات المنفذة

| الشاشة | عناصرها | التفاعل |
|---|---|---|
| الرئيسية | الاسم، بطاقة ترحيب، الأقسام الخمسة، دعوة للمقارنة، مادة للبدء | فتح القسم في المكتبة أو الانتقال للبحث والمقارنة |
| المكتبة | بطاقات الكتب الكاملة ومجموعة مرشحات | التصفية وفتح PDF الأصلي وحفظ الكتاب |
| البحث | حقل عربي ومرشحات وعدد نتائج | البحث في البيانات والموضوعات والمقارنات، وحالة عدم وجود نتائج |
| القارئ | الأصل المصور، رقم صفحة، أدوات تكبير ونافذة بيانات | تمرير الصفحة وتكبيرها، الانتقال لصفحة، حفظ، واستئناف القراءة |
| المقارنة | اختيار خمس مسائل ومذاهب وبطاقات أقوال وإحالات | عرض الأربعة أو مذهب محدد، وإظهار الجزء والصفحة والطبعة وفتح المصدر |
| محفوظاتي | الكتب المحفوظة وحالة البداية الفارغة | فتح الكتاب عند آخر صفحة أو إزالته من المحفوظات |

تظهر بيانات المصدر والإتاحة لكل كتاب، وتُميز صفحات ملف PDF عن أرقام الطبعات المطبوعة. لا تُعرض إحصاءات مراجعين غير موجودة. المقارنات ملخصات منسوبة إلى موسوعة فقهية محددة الطبعة والصفحة.

## ما يلي هذه الدفعة

نقل نصوص الواجهة إلى موارد ترجمة، فصل طبقة العرض عن الحالة مع نمو المشروع، اعتماد مخطط مصادر وطبعات ومواضع نصية، إضافة بيانات مراجعة علمية، ثم إدخال دفعة كتب مصرح بها. تُراجع أحجام الخط والتباين وTalkBack على أجهزة متنوعة قبل إصدار عام.
