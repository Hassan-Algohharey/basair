# بصائر 0.16.0 — سجل البحث المحلي

السجل مشترك بين المكتبة والبحث العام ودليل الشيوخ والدروس. يفتح من أزرار «سجل البحث» تحت حقول البحث، ومن الرئيسية. تعرض كل عملية كلمات البحث والقسم الذي صدرت منه، والأحدث أولًا.

## الحفظ والاستعادة

- الحفظ مفعل افتراضيًا، ويحدث عند الضغط على زر «بحث» أو إجراء البحث في لوحة المفاتيح، أو فتح نتيجة بحث: كتاب أو مقارنة أو مدخل مرتبط في البحث العام، أو صفحة شيخ أو مادة أو سلسلة في الدليل. لا تحفظ الكتابة حرفًا حرفًا، ولا تحفظ الكلمات بمجرد فتح الشاشة أو مغادرتها.
- يحتفظ بآخر50 بحثًا، حتى200 حرف للبحث. يظل البحث الطويل يعمل، لكنه لا يضاف للسجل. تستبعد الكلمات الفارغة وتوحد المسافات، ويمنع التكرار داخل القسم مع تجاهل التشكيل وبعض صور الحروف العربية وحالة الأحرف الإنجليزية. إعادة استخدام بحث تحركه إلى الأعلى عندما يكون الحفظ مفعلًا.
- البحث نفسه في قسمين يبقى عمليتين مستقلتين. يصنف البحث العام مع الكتب، ويصنف بحث أسماء الشيوخ وعناوين الدروس داخل الدليل مع الشيوخ والدروس.
- اختيار عملية قديمة يعيد كلماتها ويفتح قسمها. تصفر فلاتر القسم والمذهب والباب للبحث العام، وفلاتر الشيخ والسلسلة والمفضلة للدليل، حتى لا تخفي فلاتر قديمة نتائج البحث المستعاد. لا يعاد فتح تسجيل خارجي أو تنزيل كتاب تلقائيًا.

## التحكم والحذف

يمكن حذف عملية واحدة أو حذف السجل كله فورًا. التعطيل يوقف الإضافات من جميع مداخل الحفظ، بما فيها فتح النتائج وإعادة استخدام بحث قديم، مع إبقاء السجل السابق متاحًا إلى أن يحذفه المستخدم. يستمر البحث الطبيعي عند التعطيل. يبقى الاختيار بعد إعادة تشغيل التطبيق أو تغيير اللغة.

حذف السجل لا يمسح الكتب أو المحفوظات أو الملاحظات أو مواضع القراءة والاستماع. لا يعيد فتح الصفحة أو تفعيل الحفظ إحياء السجل المحذوف؛ لا يضاف بحث إلا بفعل جديد من المستخدم.

## الخصوصية والتخزين

تخزن الكلمات والقسم وترتيب القائمة وإعداد الحفظ في تفضيلات خاصة بالتطبيق باسم `basair-search-history`. لا يخزن وقت أو موقع أو حساب لكل عملية. لا شبكة أو تحليلات أو حساب أو خدمة مزامنة لهذه الميزة، ولا أذونات جديدة. يظل إعداد `allowBackup=false` للتطبيق كما هو. يحذف مسح بيانات التطبيق أو إزالته السجل وإعداده مع بقية البيانات المحلية.

البحث داخل الفهارس محلي، ولا يرسل سجل الكلمات إلى مصادر الكتب والتسجيلات. عندما يفتح المستخدم كتابًا أو مصدرًا خارجيًا، يبقى طلب الملف أو الصفحة خاضعًا لسياسة المصدر كما توضحه سياسة الخصوصية؛ لا يرسل التطبيق معه سجل البحث.

الواجهة بالعربية والإنجليزية. تفاصيل التحقق الفعلي على الهاتف والحزمة في [سجل الاختبارات](TESTING_AR.md). لا يتضمن التحديث رفعًا إلى Google Play.
